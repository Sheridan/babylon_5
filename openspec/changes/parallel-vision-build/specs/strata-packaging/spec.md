# Spec Delta

## MODIFIED Requirements

### Requirement: Опциональный кодировщик изображений
Флаг `vision` SHALL добавлять сборку и установку кодировщика изображений `strata-vision`, расширяющего веб-интерфейс вводом картинок; по умолчанию флаг выключен и кодировщик не устанавливается. Сборка кодировщика SHALL использовать распараллеливание в соответствии с `MAKEOPTS`.

#### Scenario: Установка с vision
- **WHEN** пакет установлен с `USE=vision`
- **THEN** исполняемый файл `strata-vision` входит в состав пакета

#### Scenario: Установка по умолчанию
- **WHEN** пакет установлен без флага `vision`
- **THEN** `strata-vision` в состав пакета не входит

#### Scenario: Сборка с учётом MAKEOPTS
- **WHEN** пакет собирается с `USE=vision` и `MAKEOPTS="-j16"`
- **THEN** компиляция единиц кодировщика выполняется параллельно (до ~16 задач), а не последовательно
