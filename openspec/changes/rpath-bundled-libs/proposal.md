# Why

В `CMAKE_EXE_LINKER_FLAGS` прописан runpath `$ORIGIN` (строка ~96), а библиотеки CUDA/ROCm runtime копируются рядом с бинарником компонента (строки ~211–232). Для общих библиотек (`CMAKE_SHARED_LINKER_FLAGS`) runpath не задаётся, и systemd-юнит не выставляет `LD_LIBRARY_PATH`. Если какой-либо из установленных ELF-файлов (движок, `strata-vision`, `.so`) не находит копируемую библиотеку по own-directory пути, запуск сервиса падает на `libnvrtc`/`librocblas` — нужен аудит NEEDED/RPATH и, при подтверждении, расширение runpath на все артефакты.

## What Changes

- Проверить (objdump/ldd) фактическую разрешимость библиотек установленных артефактов без окружения; если обнаружен пробел — задать `$ORIGIN`-runpath и для общих библиотек, и для всех исполняемых файлов компонентов.
- Если аудит покажет, что всё находится и без изменений — изменение закрывается решением «фиксация аудита в README» без правки ebuild.
