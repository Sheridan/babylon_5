# Design

## Context

Сейчас (ebuild, строки 314–331): при `USE=cuda|hip` собирается строка `engine_pre` вида `-/bin/sh -c 'test -e <stamp> || strata components add-build <dir> && touch <stamp>'`, каталог компонента берётся перебором `${ED}/usr/lib/strata/engine/*/`, затем строка экранируется от `|`/`&` и вставляется `sed`-ом в шаблон; без GPU-флагов строка удаляется из шаблона тем же `sed`. SysV/openrc-альтернатив юниту нет — скрипт нужен только systemd.

## Goals / Non-Goals

**Goals:** весь shell рантайм-шага — в одном редактируемом, исполняемом, просматриваемом файле пакета; юнит статичен; семантика «успех — тихо, сбой — сообщение с кодом в журнал, запуск не срывается, повторный запуск идемпотентен» сохранена.
**Non-Goals:** не менять обёртку `/usr/bin/strata` и генерацию `BUILD.json` (build-time-подстановки); не менять политику автозапуска (см. `no-service-auto-enable`); не делать регистрацию строгой (срыв старта) — см. решение пользователя в `visible-engine-reg-pre`.

## Decisions

- **Каталог движка ищется скриптом в рантайме** (`find /usr/lib/strata/engine -mindepth 1 -maxdepth 1 -type d`), а не запекается при сборке: пропадает необходимость знать раскладку компонента на этапе `src_install`.
- **Код возврата скрипта — всегда 0**: при сбое регистрации скрипт печатает в stderr `strata: engine registration failed (code N)` и выходит 0; в `-`-префиксе systemd отпадает нужда, требование «bare `-` не используется» из `visible-engine-reg-pre` выполняется. Отсутствие каталога движка (сборка без GPU-флагов) — штатный тихий выход 0.
- **EPREFIX**: в скрипте пути пишутся с токеном `@EPREFIX@`, `src_install` подставляет его единственным `sed`-ом скаляра (как в `files/strata.service` нет — файл юнита статичен, в стандартном профиле EPREFIX пуст) — сохраняем корректность для префиксированных установок без экранирования shell-кода.
- Stamp-файл остаётся прежний (`/var/lib/strata/.strata-engine-added`), совместимость с уже созданными метками.
- Установка: `into /usr/lib/strata; dobin "${T}/strata-engine-register"` (после `sed`-подстановки EPREFIX) — режим 0755, владелец root:root по умолчанию.

## Risks / Trade-offs

- Скрипт, читаемый в рантайме, исполняется от имени пользователя `strata` (User= в юните) — как и прежняя команда; прав на запись в `/var/lib/strata` достаточно для stamp-файла (каталог принадлежит `strata`).
- «Уже зарегистрировано» при удалённом stamp-файле даёт сообщение о коде возврата — формулировка нейтральная; повторный `add-build` идемпотентен на уровне strata (текущий one-liner полагался на то же).
