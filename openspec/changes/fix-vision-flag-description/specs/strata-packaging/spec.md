# Spec Delta

## MODIFIED Requirements

### Requirement: Опциональный кодировщик изображений
Флаг `vision` SHALL добавлять сборку и установку кодировщика изображений (`strata-vision` для CUDA, `strata-vision-hip` для HIP), расширяющего веб-интерфейс вводом картинок; по умолчанию флаг выключен и кодировщик не устанавливается. Описание флага в `metadata.xml` и `use.local.desc` MUST соответствовать фактическим зависимостям (зависит от выбранного GPU-бэкенда; OpenCL не используется).

#### Scenario: Установка с vision
- **WHEN** пакет установлен с `USE=vision`
- **THEN** исполняемый файл `strata-vision` входит в состав пакета

#### Scenario: Установка по умолчанию
- **WHEN** пакет установлен без флага `vision`
- **THEN** `strata-vision` в состав пакета не входит

#### Scenario: Точное описание флага
- **WHEN** пользователь смотрит описание `vision` (`equery uses`, `euse`)
- **THEN** текст описывает кодировщик для CUDA/HIP-бэкенда и не упоминает OpenCL
