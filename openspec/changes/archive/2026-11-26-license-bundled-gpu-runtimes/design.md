# Design

## Context

Копируемые `.so` принадлежат проприетарным рантаймам (NVIDIA CUDA Toolkit; ROCm). В дереве лицензий доступны `NVIDIA-CUDA`, `AMD-GPU-PRO-EULA`, `NCSA-AMD`, `Apache-2.0` (часть ROCm-библиотек — Apache/MIT). Ebuild в настоящее время заявляет только MIT — неточно и юридически рискованно для оверлея.

## Goals / Non-Goals

**Goals:** LICENSE = код + реальные двоичные компоненты; тексты лицензий в пакете.
**Non-Goals:** не удалять бандлинг библиотек (он обеспечивает самодостаточность компонента).

## Decisions

- `LICENSE="MIT cuda? ( NVIDIA-CUDA ) hip? ( ROCm-набор )"`, точные идентификаторы подбираются по источникам библиотек (для ROCm-компонентов, распространяемых под NCSA-AMD/Apache-2.0 — их имена). Тексты лицензий: копируются из устанавливаемых пакетов-источников ( `/usr/share/licenses/...` тулкита) или из дерева `licenses/` — как принято в оверлее (пример: opencode-bin?).
- Альтернатива — получить у upstream явное разрешение и ничего не менять — вне рамок оверлея.

## Risks / Trade-offs

- Зависимость LICENSE от USE-флагов усложняет чтение — приемлемо, стандартная практика.
