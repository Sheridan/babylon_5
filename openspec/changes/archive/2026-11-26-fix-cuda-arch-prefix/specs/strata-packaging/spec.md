# Spec Delta

## MODIFIED Requirements

### Requirement: Сборка движка выбирается GPU USE-флагами
Пакет SHALL собирать C++ движок `strata` только когда включён `cuda` или `hip`, с зависимостями от соответствующего тулкита; одновременное включение обоих флагов MUST блокироваться через REQUIRED_USE, поскольку система сборки upstream запрещает оба бэкенда сразу. Значения архитектур CUDA, передаваемые в компилятор, MUST быть корректными идентификаторами (`sm_<arch>`/`compute_<arch>` без искажений и повторяющихся префиксов).

#### Scenario: NVIDIA-сборка
- **WHEN** пакет устанавливается с `USE=cuda`
- **THEN** движок компилируется с CUDA-бэкендом и исполняемый файл движка устанавливается в систему

#### Scenario: AMD-сборка
- **WHEN** пакет устанавливается с `USE=hip`
- **THEN** движок компилируется с HIP/ROCm-бэкендом и исполняемый файл движка устанавливается в систему

#### Scenario: Конфликт бэкендов
- **WHEN** пользователь пытается установить пакет с `USE="cuda hip"`
- **THEN** Portage отклоняет установку с предупреждением REQUIRED_USE, не начиная сборку

#### Scenario: Корректная нотация архитектуры CUDA
- **WHEN** сборка с `USE=cuda` и архитектурой `sm_120`
- **THEN** в командах компиляции фигурирует `sm_120` (и/или соответствующий `compute_120`), значение вида `sm_sm_120` отсутствует
