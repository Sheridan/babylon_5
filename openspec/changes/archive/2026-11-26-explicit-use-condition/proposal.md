# Why

Строка `use cuda || use hip && targets+=( strata )` в `src_compile` читается как ошибка приоритета: в POSIX-оболочках `&&` и `||` равноприоритетны и левоассоциативны, поэтому выражение эквивалентно `(use cuda || use hip) && targets+=( strata )` и работает правильно — но каждый ревьюер (и этот отчёт включительно) вынужден это перепроверять, а правая часть условия будущим редактором легко будет испорчена.

## What Changes

- Расставить явные скобки: `if use cuda || use hip; then targets+=( strata ); fi` (или `&&( ... )`), без изменения поведения; аналогичные составные условия в ebuild проверить на читаемость.
