# Design

## Context

Баш: `A || B && C` группируется как `(A || B) && C` (равный приоритет, левая ассоциативность). Текущая строка корректна по смыслу, но спорна по читаемости; в ходе code review была ошибочно помечена как баг приоритетов — это подтверждает проблему читаемости.

## Goals / Non-Goals

**Goals:** недвусмысленная форма условия.
**Non-Goals:** не менять семантику.

## Decisions

- Переписать в `if use cuda || use hip; then targets+=( strata ); fi`. Aльтернатива `use cuda || { use hip && ...; }` — нет, меняла бы логику.

## Risks / Trade-offs

- Нулевой риск при проверке трёх USE-комбинаций.
