# Spec Delta

## ADDED Requirements

### Requirement: Сбой регистрации движка отражается в журнале
При неудаче шага предстартовой регистрации движка `strata.service` SHALL оставлять в журнале systemd различимое сообщение с кодом возврата, без срыва запуска сервера; полное подавление ошибок шага (голый префикс `-`) MUST NOT использоваться.

#### Scenario: Успешная регистрация
- **WHEN** сервис запускается на системе с зарегистрированным/регистрируемым движком
- **THEN** сервис активен, сервер отвечает на localhost

#### Scenario: Видимый сбой
- **WHEN** регистрация движка завершается ошибкой (например, каталог данных недоступен на запись)
- **THEN** в `journalctl -u strata` присутствует сообщение о неуспехе регистрации с кодом возврата
