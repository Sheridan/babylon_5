# Design

## Context

Systemd-префикс `-` у ExecStart скрывает ненулевой код возврата и не пишет в журнал причину. Регистрация идемпотентна? Повторный вызов регистрации может возвращать ошибку «уже зарегистрировано» — поэтому и стоял `-`.

## Goals / Non-Goals

**Goals:** различимая диагностика сбоя в `journalctl -u strata`.
**Non-Goals:** не срывать старт сервера при недоступности движка (сервер может работать и догонять регистрацию — решение пользователя).

## Decisions

- `ExecStartPre=/bin/sh -c '<cmd> || echo "strata: engine registration failed (code $?)"'` — ошибка видна, сервис стартует. Альтернатива — сделать регистрацию идемпотентной и снять `-` — строже, но меняет поведение отказа (сервис не стартует) без запроса пользователя.

## Risks / Trade-offs

- Шум в журнале при легитимном «уже зарегистрировано» — формулировку сообщения сделать нейтральной («registration step returned code N»).
