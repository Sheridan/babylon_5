# Spec Delta

## ADDED Requirements

### Requirement: Документация согласована с комплектом и обновлением
README пакета MUST NOT противоречить устанавливаемым файлам: описание каналов лога соответствует фактическому содержимому `strata.json` и юнита; упоминания несуществующих файлов (например, `harness.log`) отсутствуют; поведение файлов `/etc/strata` при обновлении пакета (сохранение правок пользователя через CONFIG_PROTECT, новые варианты как `._cfg*`) описано в README.

#### Scenario: Кросс-проверка документов
- **WHEN** сопоставить README.gentoo с `strata.json`, `daemon.conf` и `strata.service`
- **THEN** адреса, порты, пути логов описаны одинаково, ссылки на несоздаваемые файлы отсутствуют

#### Scenario: Сохранение правок при обновлении
- **WHEN** пользователь отредактировал `/etc/strata/strata.json` и затем обновил пакет
- **THEN** отредактированный файл сохранён, новый вариант установлен как `._cfg*`, README описывает процедуру слияния
